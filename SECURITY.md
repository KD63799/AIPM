# Sécurité

Ne signalez pas une faille dans une issue publique. Utilisez le formulaire privé de GitHub :
onglet **Security** du dépôt, puis **Report a vulnerability**.

Décrivez la faille, son impact et les étapes pour la reproduire. Vous recevrez une réponse
sous sept jours, et le correctif sera publié avant tout détail public.

Seule la dernière version de la branche `main` reçoit des correctifs.
